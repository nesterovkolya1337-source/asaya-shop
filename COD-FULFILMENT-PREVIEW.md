# ASAYA: сборка заказов с оплатой при получении

Подтверждённый Яндексом заказ с оплатой при получении теперь можно взять в сборку, проверить комплектацию и зафиксировать фактическую отгрузку через админку сайта.

Способ оплаты проверяется на бэкэнде по связанной с заказом сессии Яндекса: нужное окружение, on_delivery, успешное подтверждение размещения и внешний номер заказа. Обычный неоплаченный заказ или позднее подтверждение после отмены не дают такого разрешения. Каждое действие повторно проверяет состояние заказа под блокировкой.

В карточке показано, что деньги ещё не подтверждены. Статус оплаты остаётся pending. После уведомления Яндекса о доставке сохраняется сигнал для сверки поступления денег. Ручное завершение неоплаченного заказа остаётся недоступным. Существующая статистика не включает неоплаченные заказы в сумму продаж.

Фиксация отгрузки записывает уже состоявшуюся передачу перевозчику; заявку на доставку она не создаёт. Повторные действия не списывают товар второй раз.

Проверки: полный набор тестов бэкэнда, клиентские тесты, проверка типов, линтер и сборка сайта. Новые сценарии проверяют повторную сборку/отгрузку, доставку после отгрузки, сохранение неоплаченного состояния и отказ для неподходящих подтверждений.

Изменения подготовлены в рабочей копии. Реальный кабинет Яндекса и боевые операции не подключались. Новые миграции не требуются. Архив содержит накопленные изменения проекта без зависимостей и секретов.
