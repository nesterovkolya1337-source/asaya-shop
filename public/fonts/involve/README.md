# Involve

Original variable fonts from https://github.com/StefanPeev/Involve/tree/main/fonts, downloaded 2026-09-08.

Normal and Oblique support weights 400–700, including Cyrillic. Distributed with the author's SIL Open Font License in OFL.txt. Font files are unchanged.

Loaded through next/font/local so font URLs also work under the /manage base path.
