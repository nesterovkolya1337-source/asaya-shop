## Что изменено

- При подтверждённом нулевом остатке строка остаётся в корзине, приглушается и показывает «Нет в наличии». Увеличение количества запрещено; ручное уменьшение и удаление сохранены.
- Сохранённое количество отделено от количества к покупке. Если в корзине 3 единицы, а backend разрешает 1, показано «Доступно к оформлению: 1 из 3». В сумму и запрос перехода входит одна единица.
- Итог и существующий порог бесплатной доставки в ПВЗ СДЭК считаются только по доступным позициям. Окончательные условия доставки остаются в Яндекс Чекауте.
- Смешанная корзина оформляет только доступные позиции. Полностью недоступная корзина блокирует оформление и показывает объяснение.
- После восстановления остатка сохранённая строка снова участвует в покупке при очередном обновлении, без повторного добавления.
- Открытие корзины, включая внутренний переход по сайту, обновляет данные из API ASAYA. Перед запросом перехода выполняется ещё одна проверка каталога. При изменении состава, допустимого количества или суммы показывается обновлённая корзина; требуется повторное нажатие оформления.
- Действующий backend обработчик ссылки Яндекса повторно проверяет товары и остатки. При конфликте 409 интерфейс запрашивает свежие данные. Изменение корзины во время запроса отменяет переход со старым составом; двойное нажатие не создаёт второй запрос.

## Остатки и совместимость

`available` по-прежнему вычисляется из общего локального stock-layer, с резервами и существующими ограничениями свежести источника. В ответ каталога ASAYA добавлен только `stockState: known | unknown`, чтобы отличать подтверждённый ноль от отсутствия данных, устаревшей выгрузки или ошибки источника. Эта метка выводится из существующих таблиц, нового stock/cache нет.

При ошибке получения каталога строки сохраняются, наличие считается неподтверждённым и оформление блокируется. Старый ответ API без метки при available=0 трактуется как unknown; положительное подтверждённое available сохраняет совместимость. В интерфейсе unknown не называется «Нет в наличии».

Контракт запроса перехода прежний: только `items: [{sku, quantity}]`. Недоступные строки не включаются. Метка `stockState` не является полем Яндекса и не передаётся провайдеру. YCP server methods, синхронизация СДЭК, создание отправлений, цены и публикация товаров не изменялись. Старый тестовый checkout сохраняет строгую проверку всей корзины; частичная покупка включена в текущей корзине Яндекса.
