## Design and implementation
User supplied replacement references in Figma file 9FHGMEfYWtTfWq9Ny2jxMg:
- 457:2842 — full cart composition.
- 457:3226 — compact cart composition.
Both read with get_design_context after connector authentication. Light grey panels, white product image surfaces, outlined quantity pills, exported remove icon, black CTA, pink accent and product recommendations adapted to existing React/CSS Modules.
No new header/footer or PDP design. Catalog product photos and saved crops remain canonical. Responsive sizes updated for cart/recommendation images.

Removed the manual price/stock refresh action and the cart's explanatory Yandex registration note. Existing refresh on entry and pre-checkout revalidation remain. Main CTA is 'Оформить заказ'; existing redirect helper and payload remain unchanged. Shared one-click CTA changes from orange to neutral black. Busy label is provider-neutral.

Delivery bar uses server shippingRemainingMinor/freeShippingMinor; quantity badge uses existing quantityProgress. Canonical price math is unchanged. Summary labels goods total explicitly because paid delivery is determined at checkout.
Authenticated loyalty is only displayed when server quote.loyalty exists; guest sees a compact sign-in link. No fabricated zero balance or redemption control. Balance has short '1 балл = 1 ₽' secondary copy.
Recommendations: up to four deterministic products from the existing public Published catalog, excluding current cart and inactive/no-SKU records. Original catalog is not mutated. Unavailable items cannot be added. No Admin/draft data is queried, no fake ratings are displayed.
