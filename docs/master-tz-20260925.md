# ASAYA Master TZ — 25.09.2026

Без production deploy. Проверки и импорт выполнены в отдельной временной локальной PostgreSQL.

## Реализовано
- Responsive packshot delivery: исходные PNG Figma → trim → WebP 94 / alpha 100, без повторного lossy-кодирования из старого WebP и без upscale. Общий srcset для PDP и карточек; lazy loading сохранён. Нового формата/CDN нет, библиотека Rich Content не регенерировалась.
- Quick Buy убран из shared listing cards. Add → stepper использует прежний cart state. Quick Buy в PDP и прежняя sticky-механика сохранены.
- PDP и Cart используют ProductRecommendations с общими карточками, стилями и touch/drag rail. Алгоритмы выбора не менялись. Прежнее ограничение действий при активном локальном промокоде сохранено.
- Mobile product-info: padding, line-height и вертикальный ритм, три строки benefits. Involve из предыдущей задачи сохранён.
- Desktop Rich Content: компактные компоненты по сохранённым актуальным Figma frames для Shampoo 527:5280, Multi_Spray 520:1929, Balm 523:4499, Mask_Spray 523:3742, Mask 530:5905, Glow 511:3538, Lift 504:1878. Расширенные legacy-абзацы убраны только из desktop presentation. Canonical facts и mobile copy не изменены. Patch ограничен точным ранее проверенным текстом, чтобы не затирать последующие ручные изменения Admin. Остальные уже исправленные композиции не переписывались.
- Reviews: существующая таблица расширена source/external_key/author/date и timestamps модерации/ответа. Импортированные записи не требуют customer/order и не получают бонусы.
- Public aggregate/count — только Published; PDP и cards используют данные backend, zero state без фиктивного среднего. Public review list имеет pagination по 100 записей.
- Customer submit продолжает требовать авторизованного покупателя с подтверждённой оплаченной покупкой; новые отзывы Pending. Прежний ledger и правило +100 сохранены.
- Отдельный Admin → Отзывы: статусы, поиск SKU/товар/автор, rating/date/answer filters, detail pane, hide/publish/reply. Скрытый отзыв не удаляется; ответ сохраняет автора и timestamp.
